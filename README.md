# Portfolio Website

### Personal Portfolio - Technical Product Manager

A responsive portfolio website built with HTML, CSS, and JavaScript showcasing professional experience and technical skills.

![Portfolio Preview](/images/portfolio-preview.png)

## Features

- Clean, modern UI design
- Fully responsive layout
- Smooth scrolling navigation
- Professional experience showcase
- Skills and competencies section
- Contact form integration
- Optimized for performance

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with flexbox and grid
- **JavaScript** - Interactive elements
- **No frameworks** - Vanilla implementation for fast loading

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize content in `index.html`
4. Update styles in `index.css`
5. Replace images in `/images` folder

## Project Structure

```
portfolio/
├── index.html          # Main HTML file
├── index.css           # Stylesheet
├── images/             # Image assets
└── README.md           # Project documentation
```
